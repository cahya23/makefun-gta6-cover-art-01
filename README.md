Vice Sunset Cover Lab — an offline web app that turns any photo and caption into GTA 6-style multi-panel cover art and exports it as a PNG. Four poster layouts (hero + 3 panels, four-panel grid, full-bleed single, tilted trio), three Vice City sunset/neon grades, per-panel crop and positioning with drag and zoom, editable title and subtitle, and one-click export in 1080x1080, 1080x1350 or 1920x1080. Photos never leave the machine. Built for the make.fun `gta6-cover-art-01` bounty ("Make GTA 6 Cover Art").

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
